# BlogApp

## 블로그 애플리케이션 (A 팀)

게시글을 관리할 수 있는 애플리케이션입니다.
블로그 주인은 블로그 게시글을 등록/수정/삭제/조회 등 관리할 수 있습니다.

### 팀 구성 및 담당 기능

| 담당자 | 담당 기능 |
| --- | --- |
| 류지훈 | 게시글 등록, 댓글 수정하기, 블로그 이웃 관리 |
| 김경환 | 게시글 목록, 댓글 삭제하기, 이웃 신청 |
| 엄예진 | 게시글 상세 조회, 댓글 좋아요 하기, 이웃 맺기 |
| 이한결 | 게시글 발행, 블로그 사용자 등록 |
| 최형선 | 게시글 좋아요 하기, 블로그 사용자 탈퇴 |
| 최미서 | 댓글 달기, 블로그 사용자 로그인, 이웃 해제 |

---
## 담당자별 상세 요구사항

### 류지훈

#### 게시글 등록
- 블로그 주인은 게시글을 등록할 수 있습니다.
- 게시글의 정보는 다음과 같습니다.
  1. 게시글 번호
  2. 게시글 제목
  3. 게시글 내용
  4. 게시 날짜
  5. 발행 여부 (발행, 미발행)
  6. 게시글 태그 (#블로그, #게시글, ...)

#### 댓글 수정하기
- 댓글을 작성한 사용자는 자신이 작성한 댓글을 수정할 수 있습니다.
- 수정 가능한 댓글 내용은 다음과 같습니다.
  1. 댓글 내용
- 좋아요 수가 1개라도 있는 댓글은 수정할 수 없습니다.

#### 블로그 이웃 관리
- 블로그 주인들은 서로 이웃을 신청하고 관리할 수 있습니다.

---

### 김경환

#### 게시글 목록
- 블로그 주인은 게시글 목록을 조회할 수 있습니다.
- 블로그 주인이 게시글 목록을 조회할 경우 미발행된 게시글까지 조회됩니다.
- 블로그 주인이 아닌 다른 사용자가 조회할 경우 발행된 게시글만 조회됩니다.
- 목록에 노출되는 정보는 다음과 같습니다.
  1. 게시글 번호
  2. 게시글 제목
  3. 댓글의 수
  4. 좋아요 수
  5. 조회 수

#### 댓글 삭제하기
- 댓글을 작성한 사용자는 자신이 작성한 댓글을 삭제할 수 있습니다.
- 좋아요 수가 1개라도 있는 댓글은 삭제할 수 없습니다.

#### 이웃 신청
- 블로그 주인은 다른 블로그의 주인에게 이웃을 신청할 수 있습니다.
- 이미 신청된 블로그 주인에게 다시 신청할 수는 없습니다.

---

### 엄예진

#### 게시글 상세 조회
- 블로그 주인이 게시한 글을 조회할 수 있습니다.
- 블로그 주인이 아닌 사용자는 발행된 게시글만 조회할 수 있습니다.
- 게시글 상세 조회를 할 경우, 조회 수가 하나 증가됩니다.
- 이미 조회를 한 사용자가 다시 조회할 경우 조회 수는 증가되지 않아야 합니다.
- 게시글 상세 조회에 노출되는 정보는 다음과 같습니다.
  1. 게시글 번호
  2. 게시글 제목
  3. 댓글의 수
  4. 좋아요 수
  5. 조회 수
  6. 게시(발행) 날짜
  7. 게시글 내용
  8. 조회한 사용자 목록
  9. 좋아요 한 사용자 목록
  10. 댓글 목록 (사용자명, 댓글 내용, 댓글 작성 날짜, 댓글 좋아요 수)

#### 댓글 좋아요 하기
- 댓글에 좋아요를 할 수 있습니다.
- 자신이 작성한 댓글에는 좋아요를 할 수 없습니다.
- 한번 좋아요를 한 댓글에는 중복해서 좋아요를 할 수 없습니다.

#### 이웃 맺기
- 신청을 받은 블로그 주인은 이웃을 등록할지, 거부할지 선택할 수 있습니다.
- 이웃을 등록할 경우, 블로그 주인의 이웃 목록에 추가됩니다.
- 이웃을 등록하지 않을 경우, 블로그 주인의 이웃 목록에 추가되지 않습니다.

---

### 이한결

#### 게시글 발행
- 블로그 주인이 작성한 게시글을 발행할 수 있습니다.
- 조회된 게시글 목록에서 발행되지 않은 게시글을 선택해, 발행할 수 있습니다.

#### 블로그 사용자 등록
- 블로그를 사용하기 위해 반드시 사용자를 등록해야 합니다.
- 사용자의 정보는 다음과 같습니다.
  1. 사용자 아이디
  2. 사용자 명
  3. 사용자 비밀번호
  4. 블로그의 이름

---

### 최형선

#### 게시글 좋아요 하기
- 블로그 주인은 자신의 게시글에 좋아요를 할 수 없습니다.
- 블로그에 방문한 사용자는 해당 블로그의 게시글에 좋아요를 할 수 있습니다.
- 좋아요를 한번 한 사용자는 같은 게시글에 중복해서 좋아요를 할 수 없습니다.

#### 블로그 사용자 탈퇴
- 더 이상 블로그를 사용하지 않을 사용자는 탈퇴할 수 있습니다.

---

### 최미서

#### 댓글 달기
- 블로그에 방문한 사용자는 게시글에 댓글을 작성할 수 있습니다.
- 댓글에 포함되는 정보는 다음과 같습니다.
  1. 사용자 명
  2. 댓글 내용
  3. 댓글 작성 날짜
  4. 댓글을 작성한 사용자의 아이디

#### 블로그 사용자 로그인
- 블로그에 게시글 또는 댓글을 작성하기 위해서는 반드시 로그인해야 합니다.
- 로그인에 필요한 정보는 다음과 같습니다.
  1. 사용자 아이디
  2. 사용자 비밀번호
- 비밀번호가 10회 이상 틀릴 경우 로그인할 수 없습니다.

#### 이웃 해제
- 이웃을 맺고 있던 블로그 주인을 해제할 수 있습니다.
- 이웃을 해제하게 되면, 서로의 이웃에서 제거됩니다.
